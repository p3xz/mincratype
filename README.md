## About

MinCraType is a browser-based typing speed test with a Minecraft-inspired visual theme. Test your WPM, track your accuracy, and level up your keyboard skills — no installation required.

## Features

- ?? Minecraft-inspired UI theme
- ?? Real-time WPM (words per minute) tracking
- ? Live accuracy measurement
- ?? Leaderboard support
- ?? Stats dashboard
- ?? Responsive design
- ?? Zero dependencies — pure HTML, CSS & JS

## Getting Started

No build tools required.

```bash
git clone https://github.com/p3xz/mincratype.git
cd mincratype
```

Open `index.html` in your browser.

- HTML5
